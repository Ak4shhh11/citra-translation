# Praktikum Pengolahan Citra Digital
## Implementasi Image Transformation Menggunakan Python

### 1. Deskripsi Proyek

Proyek ini merupakan implementasi praktikum mata kuliah **Pengolahan Citra Digital** yang membahas proses transformasi citra menggunakan bahasa pemrograman Python.

Pada praktikum ini, saya menggunakan satu gambar dengan format JPG atau PNG sebagai citra asli. Selanjutnya, gambar tersebut diproses menggunakan beberapa teknik transformasi untuk melihat perubahan posisi, ukuran, orientasi, dan pencerminan gambar.

### 2. Tujuan Praktikum

Tujuan dari praktikum ini adalah:

1. Memahami konsep dasar transformasi citra digital.
2. Mengimplementasikan Translation untuk menggeser posisi gambar.
3. Mengimplementasikan Scaling untuk mengubah ukuran gambar.
4. Mengimplementasikan Rotation untuk memutar gambar.
5. Mengimplementasikan Horizontal Flip dan Vertical Flip.
6. Membandingkan citra asli dengan hasil dari setiap transformasi.

### 3. Teknologi yang Digunakan

Beberapa library Python yang digunakan dalam proyek ini adalah:

| Library | Fungsi |
|---|---|
| Python | Bahasa pemrograman utama |
| OpenCV | Melakukan proses transformasi citra |
| NumPy | Operasi matriks dan array citra |
| Matplotlib | Menampilkan citra asli dan hasil transformasi |
| Pillow | Membaca dan mengolah file gambar |

### 4. Jenis Transformasi Citra

Berikut merupakan transformasi yang diimplementasikan dalam praktikum ini.

#### A. Translation

Translation merupakan proses menggeser posisi objek atau gambar berdasarkan koordinat sumbu X dan Y.

#### B. Scaling

Scaling merupakan proses mengubah ukuran citra dengan menggunakan faktor skala tertentu.

- Scaling 0,5: memperkecil ukuran gambar menjadi setengah dari ukuran awal.
- Scaling 2: memperbesar ukuran gambar menjadi dua kali ukuran awal.

#### C. Rotation

Rotation merupakan proses memutar gambar berdasarkan sudut tertentu.

Sudut rotasi yang digunakan:
- 45°
- 90°
- 180°

#### D. Horizontal Flip

Horizontal Flip merupakan proses pencerminan gambar secara horizontal, sehingga bagian kiri dan kanan gambar bertukar posisi.

#### E. Vertical Flip

Vertical Flip merupakan proses pencerminan gambar secara vertikal, sehingga bagian atas dan bawah gambar bertukar posisi.

### 5. Hasil Praktikum

Pada praktikum ini, hasil transformasi yang ditampilkan meliputi:

| No. | Jenis Citra | Keterangan |
|---|---|---|
| 1 | Original Image | Gambar asli sebelum transformasi |
| 2 | Translation | Gambar setelah mengalami pergeseran |
| 3 | Scaling 0,5 | Gambar diperkecil |
| 4 | Scaling 2 | Gambar diperbesar |
| 5 | Rotation 45° | Gambar diputar 45 derajat |
| 6 | Rotation 90° | Gambar diputar 90 derajat |
| 7 | Rotation 180° | Gambar diputar 180 derajat |
| 8 | Horizontal Flip | Gambar dicerminkan secara horizontal |
| 9 | Vertical Flip | Gambar dicerminkan secara vertikal |

Seluruh hasil transformasi dibandingkan dengan citra asli untuk mengetahui perubahan yang terjadi setelah setiap proses dilakukan.

### 6. Kesimpulan

Berdasarkan praktikum yang telah dilakukan, saya memahami bahwa transformasi citra digital dapat digunakan untuk mengubah posisi, ukuran, orientasi, dan tampilan suatu gambar.

Setiap metode memiliki fungsi yang berbeda. Translation digunakan untuk menggeser gambar, Scaling untuk mengubah ukuran, Rotation untuk memutar gambar, sedangkan Flip digunakan untuk menghasilkan pencerminan gambar.

Melalui praktikum ini, saya dapat memahami penerapan dasar pengolahan citra digital menggunakan Python dan beberapa library pendukungnya.
